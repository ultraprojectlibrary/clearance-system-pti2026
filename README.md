# clearance-system-pti2026
development of a clearance system for final year student using PTI as case study for this project

IDE INSTALLATION & SETUP FOR CLEARANCE SYSTEM 2026
STEP 1:
Download python V3.12.7 from official website ( https://www.python.org/downloads/release/python-3127/) following installation process carefully and when it is done click OK.

STEP 2: 
Download VScode from official website (https://code.visualstudio.com/download ) following installation process carefully and when it is done click OK.

STEP 3:
Open VScode , click on extension , search and install the following
Live server
Djangohtml
Python extension
Django template extension

STEP 4: 
Open command prompt on your PC, type or copy this command to install the following
django 
pillow 
django-crispy-forms
Command > pip install django pillow django-crispy-forms
gunicorn 
whitenoise 
virtualenvwrapper-win
Command > pip install gunicorn whitenoise virtualenvwrapper-win
